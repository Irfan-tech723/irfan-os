# IRFAN OS

An immersive developer portfolio built with **Next.js**, **TypeScript**, **React Three Fiber**, **Three.js**, and **GSAP**.

Designed as a futuristic private R&D operating system rather than a traditional portfolio.

## ✨ Features

- 🎮 Hidden Game Center
- 🤖 IRFAN AI Assistant
- 🖥️ Desktop Mode
- 💻 Terminal Navigation
- 🌍 Interactive Globe
- 📚 Knowledge Books
- 🏆 Achievement System
- 🌧️ Matrix Mode
- ⚙️ Developer Mode
- 🎙️ Voice Commands

## 🛠 Tech Stack

- Next.js
- TypeScript
- React Three Fiber
- Three.js
- GSAP
- Tailwind CSS
